# Emad Khan

I build production AI systems with Claude Code and the Claude API, and I teach people to build them.
LSE Philosophy & Economics student. Founder of [Columen Consulting](https://columenconsulting.com).

### What I've shipped

- **AI video-review engine.** It turns a creator's short-form video into the critique a coach would give. The pipeline is Whisper transcript → Claude vision decode → evidence-checked findings → written review. It's live for a creator-coaching company and graded by evals against the coach's own past reviews, with 644 tests behind it.
- **White-label client platform.** A member portal with a roadmap, tracker, course player, intake form, admin and a CSM cockpit, themed per client from one codebase. Built with Next.js, Supabase and Postgres RLS.
- **Headless Claude Code agent.** A Telegram bot that generates images and video for a client's editor on a shared account, without the editor ever getting the login. Tools are restricted to one CLI, and a PreToolUse hook outside the model enforces a daily spend cap.
- **Wu**, my personal AI system. It's a Telegram agent plus a voice/text PWA, with headless Claude runs that sweep my mail, calendar and university Moodle into one event log. It includes an Obsidian plugin that quizzes me on my courses every day.

### How I work with Claude

I've written my own Claude Code skills and subagents. One example is *plan-council*: a plan goes to a council of review lenses, then an adversarial pass re-checks every claim against the real code before anything gets built.
